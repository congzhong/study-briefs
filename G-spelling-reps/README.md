# 问题单 G｜孩子学会拼写一个英语单词，要练几次？（给 GPT-6 Pro）

你好。我们在做一个给 8–11 岁小学生学英语单词的手机游戏（自走棋＋回合制冒险）。你上一轮已经帮我们写过韩国教材 U1–U5 的逐词内容表，这次请你帮忙解决**数值的地基**。我们需要一个**来自研究文献的外部锚点**，用来校验我们自己的模拟。我们的模拟已经被证明偏乐观：几次改版后，孩子"随便上棋子都能通关"。

## 游戏里和这个问题有关的事实

- **孩子**：8–11 岁，母语是韩语或中文，英语是外语。课本是韩国小学三年级起步的教材（第一单元的词：I、am、is、hello、hi、goodbye、thank、you、name、bag、ball、car、chair、clock、cup、doll、pig、big、small）。
- **每一次操作都要答一道真题**：买牌、上场、合体都要答对应那张牌上的词。题目由一个自适应引擎按阶梯出，大致是：
  1. 讲解（看图、听音、看完整拼写）
  2. 认图选词
  3. 听音选词
  4. 部分拼写（藏掉一部分字母，从字母池里选）
  5. **独立拼出整个词**（不给提示）
  
  答错会退回去补，用提示的不算独立。**"本局学会"＝第一次在无提示的情况下独立拼对整个词。**学会后，这个词在本局里免题，还会让棋子变强。跨天还有间隔复习（FSRS 风格），这次先不问。
- **一场冒险战斗**：多回合。每回合先是准备阶段（拿能量买牌、上场，每次都答题，不限时），然后是自动播放的交锋。墨水怪每回合先亮意图（要打谁、打多少），血量跨回合保留。目前每回合 4 点能量，约 2–3 次购买或部署，所以**每回合大约答 2–3 题**。每回合约 1 分钟。
- **一站有 2–3 个"目标新词"**。用户刚定：**允许跨站学会**，这一站练到"部分拼写"，下一站独立拼完整个词也可以。
- **引擎里同一个词短时间内重复出现会打折**：10 分钟内再考同一个词，学习权重最低降到 0.25。我们打算规定同一个词每回合最多考 1 题（至多 2 题）。
- **我们的引擎参数都是工程初始值，没有用儿童数据校准过**（例如"会也失手"的概率按 3% 算，刚看过完整拼写有短时加成，10 分钟衰减完）。

## 请你回答的问题

1. **学会拼写要几次**：8–11 岁的 EFL 孩子，学会拼一个短的、具体的词（car、pig、bag）和一个稍长或抽象的词（goodbye、thank、chair、clock），从第一次见到，到能当场无提示拼对，**大约需要几次有效接触或提取练习**？请区分"认得""能听辨""能拼出"三个层次，并按强、中、弱三类孩子分别给数（中位数，以及 80% 的孩子能达到的次数）。没有直接证据的地方，请说明你是从哪类研究推断的。
2. **同一节课里的间隔**：一次 6–10 分钟的游戏里，同一个词隔多久再练一次最有效？连着考两次和隔一回合再考，差多少？我们"每词每回合最多 1 题"的规定合不合理？
3. **"当场拼对一次"算不算学会**：当场第一次独立拼对之后，隔一天、隔一周还能拼对的比例大概是多少？如果允许跨站学会，你建议怎么定"学会"：比如"隔一站再独立拼对一次"？
4. **验算我们的公式**：至少打几回合 ＝ max( 本站目标词所需题数之和 ÷ 每回合落在目标词上的题数 , 单个词所需题数 ÷ 每词每回合上限 )，墨水怪的血量和攻击再按"最强孩子用最优打法，也不能早于这个回合数打完"反推。这个思路有没有漏洞？例如：老伙伴、绿叶词会分走题目，孩子答错还会多出题。
5. **难度目标挑刺**：我们按三种打法定首次胜率：
   - A 只带已学会的老伙伴，基本打不过；
   - B 买了目标词但随便摆、不看意图，普通站 ≤30%；
   - C 认真学并应对意图，普通站 60–75%，头目约 50%。
   
   输了保留本局学会的词，三次以内 95% 能过；赢的局里至少三成是险胜。对 8–11 岁的孩子，这个难度会不会挫败过头？关于"失败后带着进步重试"的动机研究，有什么可以借鉴的？
6. **其他**：你认为我们没想到、但会影响"学单词效率"或"孩子愿不愿意继续玩"的关键点。
