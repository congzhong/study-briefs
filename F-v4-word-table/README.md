## 每个必会词要写的东西

**棋子词（名词类，能上场的单位）**
1. **它的本事**：一句话说清楚，要贴着词义。例如 pig 打滚连打两下、chair 让身后的伙伴坐稳不被击退。
2. **形态**：短词 2 个（刚救回→觉醒），长词或难词 3 个（刚救回→熟练→觉醒）。每个形态用一句外观描述，给美术用，要一眼认出是同一个东西越来越强。
3. **墨水怪带着它时的招式**：这个词被墨水怪困住时，墨水怪会多出的一个招式和意图图标。例如困着 clock 的墨水怪会加速，一回合打两次。
4. **台词**：被困时一句、救回时一句、上场时一句，都用课本里出现过的句子或短语，并写出处。

**效果词（形容词、动词、问候语等，不上场，是战术牌）**
1. **效果**：贴着词义，在多回合里有用。可以参考：先出手、加血、加盾、多拿牌、加能量、多刷新、群攻、斩杀、开场放大招、指定敌人目标。每个单元里不要重复太多。
2. **持续时间**：本回合，还是持续 N 回合。

**融合配方（每个单元 4–6 条）**
- 两个词融合成一个新形态：棋子＋棋子，或者效果词＋棋子。
- **必须是课本或练习册里真实出现的搭配**，写出处（页码或课次）。例如 ball＋pool → "in the pool"。
- 配方里可以用绿叶，但出题永远只考孩子点的那个必会词，绿叶不出题。
- 写清楚：融合后的名字、外观一句话、新的本事（要比两个分开时多出一个明显的新东西）。

## 底线（请严格遵守）
- 只用这本书这个单元的必会词出题；绿叶只能做配角，不出题。
- 图、词、音一一对应：本事和形态都必须让孩子一看就知道"这是 car"。
- 句子讲战场上正在发生的事；搭配从课本或练习册里取并写出处；不整句搬课文；不出现课本里的人名，也不出现场上没有的人和物。
- 数字不超过 20。具体数值由我们的数值策划定，你只要写"强、中、弱"或相对关系。
- 每一站只新教一样东西，所以请给每个单元排一个"新概念出场顺序"建议。
