# 问题单 H 附件｜冒险 v4：为什么改、从什么改成什么、背景

> 给 Muse：请**先玩、再读这一页**。制作人自己玩过几局，提了一些问题，但**他说到的不代表只有这些问题**。请你独立去找，尤其是他没注意到的。

## 一、产品背景（不变的部分）

- 给 8–10 岁小学生（韩国、中国）的英语单词游戏，手机横屏。题目和课本一一对应，这次以韩国 YBM 三年级（kr）第一单元为例。
- **铁律**：
  - 买牌、上场、合成，每次操作都要答一道真实的单词题；
  - 图、词、音一一对应：点的是哪张牌，就考哪个词；
  - 只考本单元的"必会词"，"绿叶词"只撑场景，不出题；
  - 答错永远不直接扣血；
  - 一个词在最高难度上**独立拼对一次**，就算"本局学会"，之后这一局里买它、上场都不再答题。
- **两种玩法**：
  - **联赛**：普通单词自走棋，这次没改；
  - **冒险**：一个单元一张地图，按课分区，区末有头目。对面是被墨水怪控制的单词，打赢、答对就把它救回来。

## 二、为什么要改（v3 的问题）

v3 冒险上线后，制作人亲手玩完，说了这几句原话：

> 难度太低了……越往后商店里没有要新学的必会词了。战斗没有办法感受到情境，对方的组合也没有感觉到有什么厉害的……当前还是没有感受到有趣，这是大问题。

> 杀戮尖塔、影之诗……它攻击的不是我的棋子，是攻击**我**，我会掉血……我得想办法救我的随从，这种感受也挺好。

第四批你（Muse）、GPT-6 Pro、Gemini 的诊断，加上我们内部的复盘，归结成五条：

1. **构筑目标和学习目标打架**：新词刚救回来最弱，还要答题；学会的旧词免题又强。所以最划算的打法是堆旧词，越想赢越不碰新词。
2. **战斗是自动打的**：孩子看二十几秒，没有决定可做，也看不出对面要干什么，所以没有压力、没有取舍。
3. **难度太低**：随便上棋子都能通关。数值调了几轮，每次都滑回"随便赢"。
4. **新词供应断档**：打到后面，商店里没有要新学的词了。
5. **必会词不重要**：一个词学没学会，对输赢几乎没有影响。

## 三、从什么改成什么

| 方面 | v3（原来） | v4（现在，链接带 adventureV4=1） | 想解决的问题 |
|---|---|---|---|
| 一场战斗 | 准备一次，然后自动打一场，二十几秒分出胜负 | **多回合消耗战**：每回合先准备（买牌、上场、出效果牌），交锋自动播放（这时不能操作），再进入下一回合，直到一方倒下 | 2、3 |
| 对手 | 被控制的单词阵容，看不出它要干什么 | **墨水怪每回合亮出意图**：头上写着下回合要打谁、打多少。它会打伙伴，也会打主角（主角有血） | 2 |
| 掉血 | 打输扣区域血（全区 12 滴） | 交锋中主角和伙伴都会掉血；答错依然不扣血 | 2 |
| 新词和旧词 | 新词弱、要答题；旧词强、免题 | **学会单词就是养成**：完整独立拼对一次就觉醒变强，之后免题。同一个词可以重复买，凑够份数会合体升形态（原形 → 熟练 → 觉醒，外形和大小都会变） | 1 |
| 牌库 | 本单元词随机刷 | **本站目标词 + 老伙伴 + 绿叶**。目标词学会后，自动补下一个新词；已学会的词少出现 | 4 |
| 上场限制 | 只受人口限制 | **每回合能上场的总量有限**（伙伴上场加效果牌使用，合起来算），老伙伴另有上限，目的是只靠旧词赢不了 | 1、3 |
| 必会词的作用 | 和其他牌差不多 | **每个必会词都有"用它才挡得住"的墨水怪意图**。例如：thank 给刚挡过伤的 bag 补满体力；big 让 car 下一撞更重；small 把伙伴缩小，躲过头顶攻击；hello 让 car 提前行动。效果词和棋子词一样要答题 | 5 |
| 赐福 | 买牌、上场时给棋子加成 | 规则改为：**还在学的词**打墨水怪有额外伤害，鼓励用新词 | 1 |
| 难度怎么加 | 调血量和攻击 | 如果提前学会了本站目标词，墨水怪会**召唤援兵**：小援兵押着下一个新词出场，打退它就能救回这个词，还多拿一点补给。墨水怪**不会**因为你答得好就偷偷加血 | 3、4 |
| 输了以后 | 扣血，重来 | **复盘**：指出最关键的一次没挡住，比如"第 3 回合墨水怪打 bag，你没挡；ball 在前排就能挡住"。连输两次给看得见的帮助，本局学会的词在重试时保留 | 3 |
| 融合 | 课本搭配是羁绊，凑齐加成 | 课本搭配变成**融合**：两个词合成一个新形态，比如 ball + pool | — |

## 四、我们的目标（用来判断改得对不对）

- 只带老伙伴：普通站基本赢不了（首胜 ≤10%）。
- 随便摆、不看意图：首胜 ≤30%。
- 认真打（会看意图、愿意买新词、答题偶尔错）：普通站约 65–80% 能赢，头目约 55–65%；三次之内基本都能过。
- 每回合都有压力，不能是最后一回合一记重击。
- 每站都有新词被真正学会；一站大约打 3–6 回合。
- 判断标准是两条：**对孩子体验的提升**和**学单词的效率**。

## 五、现在已知的问题（你玩的时候会碰到）

制作人玩过之后指出的问题，**不代表只有这些**：

1. **数值极不合格**：没有达到上面的目标。数值策划正在本地亲手玩、逐站重调。
2. **表现退步**：v4 改规则时，把原来的表现也换掉了。买牌、战斗特效（原来棋子会冲过去打、受击、退场，现在是一条黄线加一个数字）、觉醒仪式、赐福光效都变简单了。这不是设计要求，正在找回。
3. 很老的手机上，交锋偶尔会顿一下。
4. 牌面说明里，融合配方的小图偶尔显示不出来（比如 stage）。

**对比方法**：同一个链接去掉 `&adventureV4=1`，进的就是 v3 旧版冒险，可以两边对照着玩。
