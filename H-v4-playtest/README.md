# 问题单 H｜冒险 v4：先亲手玩，再挑错（给 Muse）


你是资深游戏设计师，同时懂儿童学习设计。上一次（第四批）你玩了旧版冒险，帮我们诊断了"为什么不好玩"。我们按那一轮的讨论（你、GPT-6 Pro、Gemini 的意见）把战斗整个重做了。这次和以前一样，**请先亲手玩，再回答**。

## 第一步：先玩（必须先做）

- 试玩站（新版必须带 `adventureV4=1`，否则进的是旧版）：
  **https://wordchess-battle-slice.vercel.app/?book=kr&lang=ko&adventure=1&adventureV4=1**
  手机横屏，或者浏览器开 844×390。
- 选第一单元（1단원），从第一站往后打，**至少打完 3 站**；有余力就打到这一区的头目。大约 20–30 分钟。
- 请故意做三件事：
  1. 有一站**只用已经会的旧伙伴**、不买新词，看能不能赢；
  2. 有一站**故意乱摆**，不看墨水怪头上的意图；
  3. 故意**输一次**，看败北页给你的复盘和重试时的帮助。
- 边玩边记：
  - 每站打了几回合、答了几题、花了几分钟、做了几个真正的决定；
  - 哪一刻最想退出、哪一刻最有意思（带截图）；
  - 墨水怪头上的意图（要打谁、打多少）**第一眼看不看得懂**；
  - 有没有出现"小援兵押着一个新词"，你看懂它是什么意思了吗。

## 第二步：这一版改了什么（玩完再看，避免先入为主）

上一轮的共识是：旧版战斗是自动打的，孩子没决定可做；构筑目标和学习目标打架（新词最弱，最划算的是堆旧词）；难度太低。v4 的改法：

1. **多回合消耗战**：一站打好几个回合。每回合先准备（买牌、上场、出效果牌），然后交锋自动播放，交锋中不能操作。
2. **墨水怪亮意图**：头上写着下回合要打谁、打多少，孩子据此摆位、出牌。它打的是伙伴，也会打主角（主角有血）。
3. **学会单词就是养成**：每个词答题、答对就上场。完整独立拼对一次就算"本局学会"，这个伙伴觉醒变强，之后买它、上场都不再答题。同一个词可以重复买，凑满份数会合体升形态（熟练 → 觉醒，形态和大小都变）。
4. **牌库 = 本站目标词 + 老伙伴 + 绿叶**。目标词学会后，牌库会自动补下一个新词；已学会的词少出现。
5. **每回合可上场的总量有限**（伙伴上场加效果牌使用，合计算），老伙伴另有上限。目的是只靠旧词赢不了。
6. **每个必会词都有"用它才挡得住"的墨水怪意图**。例如：thank 给刚挡过伤的 bag 补满体力；big 让 car 下一撞更重；small 把伙伴缩小，躲过头顶的攻击；hello 让 car 提前行动。效果词和棋子词一样要答题。
7. **召唤援兵**：如果你提前学会了本站的目标词，墨水怪会叫来一个小援兵，押着下一个新词。打退它就能把这个词救回来，还能多拿一点补给。墨水怪不会因为你答得好就偷偷加血，加难度只走这条公开的路。
8. **输了讲清楚为什么**：败北页会指出最关键的一次没挡住，比如"第 3 回合墨水怪打 bag，你没挡；ball 在前排就能挡住"。连输两次会给看得见的帮助，本局学会的词在重试时保留。
9. **答错永远不扣血**，只有交锋中被打才掉血。

## 我们自己最担心的（请重点验证，直接说对错）
1. **"一眼看懂意图"**：8–10 岁孩子能不能看懂墨水怪头上那行"要打谁、打多少"，并且想到"那我该出哪个词"？
2. **必会词真的起作用了吗**：你是因为"这个词能挡住"才去用它，还是只是因为它在商店里、答完题顺手放上去的？
3. **难度**：只带旧伙伴赢不赢得了？乱摆赢不赢得了？认真打会不会太难？我们的目标是：乱摆普通站首胜不超过约 30%，认真打 65–80%，三次之内基本都能过。
4. **答题密度**：一站答了多少题？你感觉是"在打仗时顺便答题"，还是"在做作业中间插了点战斗"？
5. **援兵**：小援兵押着新词来，你看懂了吗？它让你更想学快一点，还是像惩罚？
6. **输了以后**：复盘那句话有用吗？你想不想马上重来？
